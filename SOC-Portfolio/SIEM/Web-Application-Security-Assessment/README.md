# Web Application Security Assessment

This project demonstrates my ability to perform a structured web application security assessment using manual penetration testing techniques. The assessment focused on identifying common web application vulnerabilities, evaluating their business impact, and providing practical remediation recommendations. The project was completed as part of a cybersecurity skills assessment and has been anonymised to remove all organisation-specific information.

## Objectives

- Perform manual web application security testing.
- Identify and document security vulnerabilities.
- Assess the business impact of each finding.
- Recommend appropriate remediation measures.
- Produce a professional penetration testing report.

## Skills Demonstrated

- Web Application Penetration Testing
- Vulnerability Assessment
- Security Reporting
- Risk Assessment
- Business Impact Analysis
- Secure Coding Review
- Manual Testing Methodology

## Tools Used

- Burp Suite
- Firefox Developer Tools
- Linux Command Line
- Gobuster
- cURL
- grep
- dd

## Key Findings

The assessment identified several security weaknesses affecting the application, including:

- SQL Injection
- Broken Function-Level Access Control
- Client-Side Information Disclosure
- Administrative Route Information Disclosure
- Insecure Backend Query Construction

Each finding was analysed according to its technical severity, business impact, and recommended remediation to demonstrate a complete vulnerability assessment workflow.

## Lessons Learned

This project reinforced the importance of following a structured penetration testing methodology while maintaining clear and professional documentation. Beyond identifying vulnerabilities, I learned that communicating technical findings in a way that both developers and business stakeholders can understand is equally important.

Reviewing my completed report also highlighted the importance of performing a thorough quality assurance review before submission. Minor improvements in wording, formatting, and consistency can significantly improve the professionalism and readability of a security assessment.

## Professional Reflection

This project strengthened both my technical and analytical skills in web application security. I gained practical experience using industry-standard tools to investigate authentication mechanisms, access control, client-side security, and application architecture.

More importantly, the assessment demonstrated that successful penetration testing extends beyond discovering vulnerabilities. It requires understanding how security weaknesses affect an organisation, prioritising risk effectively, and communicating findings through clear, accurate, and actionable reporting. Going forward, I will continue refining both my technical testing techniques and my ability to produce reports that meet professional industry standards.
