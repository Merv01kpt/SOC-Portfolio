# SOC Team Internals – TryHackMe

## Overview

This project documents my completion of the **SOC Team Internals** learning path on TryHackMe. The learning path focuses on the day-to-day responsibilities of a Level 1 Security Operations Center (SOC) Analyst, covering the complete alert handling lifecycle from detection and investigation to reporting, escalation and measuring SOC performance.

Through these rooms I strengthened my understanding of enterprise SOC operations, structured investigation methodologies and the communication processes required within a security team.

# Room 1 – SOC L1 Alert Triage

## Summary

Completed training on the structured workflow used by SOC analysts to investigate and classify security alerts. The room covered distinguishing security events from alerts, understanding alert properties, prioritising alerts based on risk and determining the appropriate response.

### Key Concepts

- Events vs Alerts
- Alert Properties
- Alert Prioritisation
- Severity Assessment
- Indicators of Compromise (IOCs)
- False Positives
- Alert Triage Workflow
- Escalation Criteria

### Practical Skills

- Alert investigation

- Risk assessment
- Initial incident classification
- Escalation decision making
